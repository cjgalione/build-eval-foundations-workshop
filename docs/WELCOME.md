# 👋 Welcome — Build Your Eval Foundations

During the first 15–20 minutes, install these tools and open the workshop repository.
The workshop team will send your OpenAI and Braintrust credentials before the session.

## 1. Braintrust CLI (`bt`)

```bash
curl -fsSL https://bt.dev/cli/install.sh | bash
bt --version
```

## 2. `uv` (Python package manager)

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
uv --version
```

## 3. Get the workshop repository

```bash
git clone https://github.com/cjgalione/build-eval-foundations-workshop.git
cd build-eval-foundations-workshop
make setup
```

Bring the email with your workshop credentials. You do not need a coding agent or the
GitHub CLI for the main workshop path.
